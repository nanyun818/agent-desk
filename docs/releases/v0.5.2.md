# Agent Desk 0.5.2

首次公开发布，Windows x64 早期体验版。

## 下载

下载 **Agent-Desk-Setup-0.5.2-x64.exe**，双击安装即可。无需 Node.js、npm 或命令行。
`Source code (zip/tar.gz)` 是开发源码，不是安装程序。安装包约 145 MB。

安装包未做代码签名，请确认来自本仓库并对照 `SHA256SUMS.txt` 校验。
不要关闭安全软件或忽略恶意软件检测结果。

## 主要功能

- Claude Code / Codex CLI 历史只读导入、项目搜索、会话归档与恢复命令复制。
- GPT、Claude、DeepSeek、Kimi、通义千问与兼容 API 的文本流式聊天。
- 消息分支、修改后分支、重新生成保留原记录；任务看板及手动文件快照。
- 十套皮肤、自定义壁纸与安全 JSON 配色包导入导出。
- 桃铃透明桌宠：身体拖动、摸头计数、随手聊、最近对话续聊。
- 修复 Windows 150% 显示缩放下拖动导致桌宠尺寸不断增大的问题。

## 使用前须知

模型需要自行配置 API Key，费用由对应服务商收取，不包含订阅或免费额度。
聊天记录默认保存在本机，发送消息会将当前分支正文传给选定服务商。
目前没有自动执行命令、自动改代码、附件/图像理解、云同步或自动更新。
更新前退出应用并备份 `%LOCALAPPDATA%\AgentDesk`；卸载默认保留用户数据。

验证：28 项单元测试、网页生产构建及 Windows 桌面独立数据烟测已通过。
桌宠在 150% DPI 下连续拖动 80 次的尺寸回归测试通过；不代表所有硬件均已覆盖。
