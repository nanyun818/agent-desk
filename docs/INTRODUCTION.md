# 如何介绍 Agent Desk

## 一句话

Agent Desk 是带桃铃桌宠的本地 AI 工作台，把 CLI 历史、多模型对话和任务整理到一起，关掉窗口，下次还能接着做。

## 发给朋友

我做了一个叫 Agent Desk 的 Windows AI 工作台，想解决“昨天跟 AI 做到哪了，今天找不到”的问题。
它能导入 Claude Code 和 Codex CLI 的历史，按项目搜索记录，保留对话分支，也能连接 GPT、Claude、
DeepSeek、Kimi 等 API。界面可以换肤，还带一只叫桃铃的小桌宠，点身体就能随手聊，摸头也有回应。

软件代码开源、记录保存在本机，下载安装包后双击安装，不用配开发环境。
需要自己提供 API Key，模型费用由对应服务商收取。现在是早期体验版，欢迎反馈。

源码：https://github.com/nanyun818/agent-desk

下载：https://github.com/nanyun818/agent-desk/releases/latest

## 30 秒演示顺序

1. 搜索一段过去的对话，展示项目分类和 CLI 来源。
2. 从其中一条消息创建分支，保留原记录并继续提问。
3. 切换已配置的模型，展示共用当前分支上下文。
4. 展示关联任务，以及手动快照的差异预览。
5. 换一套皮肤，拖动桃铃，摸头，再点身体打开随手聊。

演示、录屏和截图请使用专门的测试数据；不要展示真实密钥、客户项目、私人目录或聊天记录。

## 不要这样宣传

- 不说“免费使用 GPT/Claude”，应说“软件免费，自备 API，服务商计费”。
- 不说“CLI 任务一键完整迁移”，导入只包含历史正文与工具名称，不还原执行状态。
- 不说“自动编程 Agent”，目前不自动执行命令、编辑文件或调用工具。
- 不说“任意时间点文件回滚”，只能回退到事先创建、范围受限的手动快照。
- 不说“所有数据永不离开本机”，发送消息会将该分支正文交给用户选定的模型服务商。
- 不说“Live2D 桌宠”，当前是双表情图片与轻量图层动画。
